# 基金投资纪律 v3 — 综合信号版

> **版本**: v3.0 | **制定日期**: 2026-06-17 | **回测验证**: 2023-06-01 ~ 2026-06-01

---

## 一、核心原则

1. **长期持有为主**：基金投资的核心收益来自长期持有，纪律的目的是优化买入时机
2. **只加不减**：回测验证，在A股市场3年周期内，减仓操作总体拖累收益（AI指数减仓版落后纯持有30%+）
3. **信号分级**：MA60 + PE百分位为主信号，MA100为辅助确认信号
4. **极度低估加倍**：当多个信号同时指向极度低估时，加大加仓力度

---

## 二、信号定义

| 信号 | 含义 | 计算方式 | 数据来源 |
|------|------|----------|----------|
| **MA60偏离** | 价格相对60日均线的偏离程度 | (当前价 - MA60) / MA60 × 100% | 基金净值/指数日K线 |
| **PE百分位** | 当前PE在近2年历史中的位置 | 近500个交易日PE排名百分位 | 指数PE（理杏仁/东方财富），基金用价格百分位近似 |
| **MA100偏离** | 价格相对100日均线的偏离程度 | (当前价 - MA100) / MA100 × 100% | 基金净值/指数日K线 |

### 信号组合逻辑

- **主信号触发**：MA60偏离 + PE百分位 同时满足 → 执行操作
- **辅助确认**：MA100偏离同方向 → 降低触发门槛（辅助信号）
- **三重共振**：三个信号同时满足 → 加大操作力度

### PE百分位说明

- **指数基金**：使用对应指数的真实PE百分位（理杏仁、东方财富等）
- **主动基金**：无直接PE数据，用**价格百分位**近似（近500日价格排名百分位）
  - 局限：价格百分位假设PE与价格正相关，对成长型基金偏差较大
  - 仍可作为辅助参考，但权重应降低

## 四、操作流程

### 每日检查（收盘后）

1. 查看各基金当日净值/收盘价
2. 计算MA60偏离、MA100偏离
3. 查看PE百分位（指数基金查真实PE，主动基金查价格百分位）
4. 对照上表判断是否触发信号
5. 触发则记录信号，次日操作

### 操作日（T+1）

1. 确认冷却期已过
2. 按规则金额下单
3. 记录操作到投资日志

### 信号优先级

当多个基金同时触发信号时：
1. 优先加仓偏离度最大的（跌得越多越先加）
2. B类优先于A类（B类波动小，低估机会更难得）
3. 单日总加仓不超过¥1,500

## 五、回测验证结果

### 回测条件

- **期间**：2023-06-01 ~ 2026-06-01（3年）
- **初始资金**：¥10,000
- **建仓方式**：初始建仓50%（¥5,000），剩余50%按纪律加仓
- **数据来源**：东方财富API
- **AI指数替代**：中证TMT指数（000993），波动特征类似
- **富国天惠替代**：基于沪深300模拟（1.2倍波动+alpha）
- **PE百分位**：用价格百分位近似

### 假设与局限

1. 未考虑申赎费（一般0.15%）、管理费
2. AI指数用中证TMT替代，非完全一致
3. PE百分位用价格百分位近似，对成长型基金有偏差
4. 回测基于日度数据，实际操作可能有1日延迟

### 关键发现

1. **v3加仓信号优于v2**：PE百分位辅助信号帮助在更低位置加仓，所有标的v3均优于v2
   - 沪深300：v3 +18.88% vs v2 +15.60%（+3.28%）
   - AI指数：v3 +117.36% vs v2 +102.01%（+15.35%）
   - 富国天惠：v3 +32.02% vs v2 +28.73%（+3.29%）

2. **减仓严重拖累A类收益**：AI指数减仓版落后纯持有27-36%，落后不减仓版50%+
   - 原因：AI板块处于产业趋势中，MA60偏离>18%是常态而非顶部信号
   - 减仓=在上涨趋势中丢掉筹码

3. **纪律策略在波动市中表现优异**：AI指数和富国天惠通过低位加仓，均跑赢纯持有

4. **沪深300纪律策略落后纯持有**：因2023-2024沪深300大部分时间在MA60上方，加仓机会少，大量资金闲置
   - 这说明对于波动较低的宽基，初始建仓比例应更高（70-80%）

## 六、v2 → v3 变更总结

| 项目 | v2 | v3 | 变更原因 |
|------|----|----|----------|
| 加仓信号 | 仅MA60偏离 | MA60偏离 + PE百分位 + MA100辅助 | 回测验证多信号加仓更精准 |
| A类加仓门槛 | MA60偏离<-10% | MA60偏离<-10%且PE<30% | 增加PE过滤，避免在"贵"的时候加仓 |
| A类辅助加仓 | 无 | MA60偏离<-8%且PE<20%且MA100偏离<-5% | 三重确认时降低门槛，捕获更多低位机会 |
| A类极度低估 | 无 | MA60偏离<-15%或PE<10%时加倍(¥1000) | 极端机会加大投入 |
| B类加仓门槛 | MA60偏离<-8% | MA60偏离<-8%且PE<30% | 同A类理由 |
| B类辅助加仓 | 无 | MA60偏离<-6%且PE<20%且MA100偏离<-5% | 同A类理由 |
| A类减仓 | MA60偏离>+15%减1/3 | **不减仓** | 回测证明减仓严重拖累收益 |
| 冷却期 | 加仓5日/减仓10日 | 加仓5日 | 减仓取消，冷却期简化 |

## 八、风险提示

1. 回测不等于未来表现，v3纪律在历史数据上有效不代表未来一定有效
2. PE百分位近似存在偏差，特别是对成长型基金
3. 纪律策略在单边上涨市中可能落后纯持有（资金未充分利用）
4. 建议根据市场环境灵活调整初始建仓比例：震荡市50%，明确底部70%
5. 任何纪律都不能保证盈利，请量力而行
